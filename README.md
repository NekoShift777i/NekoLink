# NekoLink

**NekoLink** — универсальный VPN-клиент для Android с открытым исходным кодом, ориентированный на гибкую настройку соединений и расширенный контроль над их параметрами.

Основная идея проекта — предоставить пользователю возможность самостоятельно управлять параметрами подключения, не ограничиваясь только базовыми настройками.

## Особенности проекта

NekoLink разрабатывается с упором на следующие принципы:

- **Гибкость настройки.** Возможность подробной настройки параметров соединения.
- **Универсальность.** Использование собственных серверов и конфигураций пользователя.
- **Контроль.** Доступ к расширенным параметрам работы клиента.
- **Открытый исходный код.** Возможность изучать, изменять и улучшать приложение.
- **Совместимость.** Поддержка различных версий Android.

> [!IMPORTANT]
> NekoLink находится на ранней стадии разработки. Описанные принципы являются целями проекта, а не перечнем уже реализованных возможностей.

## Текущее состояние

По состоянию на 25 ноября 2026 года реализовано рабочее VPN-подключение к удалённому серверу через ядро Xray с полной маршрутизацией IPv4-трафика устройства.

На данный момент реализованы:

- Запрос системных разрешений на использование VPN и отображение уведомлений.
- Запуск VPN-службы в приоритетном режиме и отображение системного уведомления.
- Управление подключением, отключением и состояниями VPN через пользовательский интерфейс.
- Интеграция libXray и проверка конфигурации перед запуском ядра.
- Создание и закрытие виртуального сетевого интерфейса TUN.
- Подключение через VLESS + XHTTP + REALITY с использованием испытательной конфигурации.
- Полная маршрутизация IPv4 и обработка DNS-запросов.
- Первоначальное разрешение доменного имени сервера через исходную сеть Android.
- Выполнение длительных операций Xray вне основного потока и синхронизация доступа к ядру.
- Обработка отмены подключения и отзыва системного разрешения VPN.
- Проверка остановки ядра перед закрытием TUN, повторные попытки отключения при ошибках и отложенное освобождение ресурсов службы.

Работоспособность VPN подтверждена на двух физических устройствах: Tecno LH6n (Android 14) и Tecno LJ9 (Android 16).

### Текущие ограничения

- Используется локальная испытательная конфигурация; импорт и управление профилями подключения пока не реализованы.
- Поддержка IPv6 и проверка отсутствия утечек IPv6 ещё не завершены.
- Отдельная проверка доступности VPN-сервера не реализована; запуск ядра сам по себе не подтверждает доступность удалённого сервера.
- Стабилизация VPN-службы продолжается, в том числе обработка блокирующих операций и повторной регистрации обработчиков защиты сокетов.

> [!NOTE]
> Проект находится на этапе стабилизации VPN-службы. Асинхронный запуск и остановка ядра реализованы и испытаны, однако приложение пока не готово к повседневному использованию и распространению.

## Системные требования

- Android 8.0 (API 26) или новее.

Минимальная версия Android задана в настройках проекта. Полноценная проверка совместимости со всеми поддерживаемыми версиями Android пока не проведена.

## Сборка из исходного кода

Для сборки потребуется Android Studio с установленными необходимыми компонентами Android SDK, включая API 37.

Библиотека libXray загружается автоматически при сборке с проверкой контрольной суммы SHA-256. Версия библиотеки и контрольная сумма задаются в `gradle.properties`.

1. Склонируйте репозиторий NekoLink.
2. Откройте проект в Android Studio.
3. Дождитесь завершения синхронизации Gradle.
4. Выберите устройство Android или эмулятор.
5. Соберите и запустите приложение.

### Испытательное VPN-подключение

Для проверки подключения необходимо самостоятельно создать файл `app/src/main/assets/xray-test.json`, содержащий исходящую конфигурацию Xray (объект `outbound`) для VLESS + XHTTP + REALITY. Файл не входит в репозиторий. Без него испытательное подключение невозможно.

> [!WARNING]
> Не добавляйте конфигурацию с действующими данными подключения в репозиторий и не распространяйте APK, собранный с такой конфигурацией: файл включается в приложение при сборке.
